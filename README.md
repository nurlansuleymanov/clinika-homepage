# Clinika Homepage

A responsive medical shop homepage recreated using HTML, CSS, and Bootstrap 5.

## Technologies

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## Features

- Responsive header with navigation menu
- Hero section with medical mask showcase
- Product cards section
- News section
- Footer with subscription and social links



## Purpose

This project was created to practice Bootstrap grid system, responsive layouts, and building a complete webpage structure from a real website design.
